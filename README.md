## 📌 About

A hands-on **Deep Learning practice repository** focused on understanding and implementing neural network architectures for both **image and sequential data**.

The practice progresses from basic neural networks to **CNNs and advanced recurrent architectures such as LSTM and GRU**.

---

## 🧩 What I Practiced

### 🧠 Neural Networks

- Artificial Neural Networks (ANN)
- Forward propagation
- Backpropagation
- Activation functions
- Loss functions
- Optimizers
- Model training & evaluation

### 🖼️ Convolutional Neural Networks

- CNN architecture
- Convolution & pooling
- Feature extraction
- Image classification
- Deep CNN architectures
- Practical image-based experiments

### 🔄 Sequence Models

- Recurrent Neural Networks (RNN)
- Long Short-Term Memory (LSTM)
- Gated Recurrent Units (GRU)
- Bidirectional RNN/LSTM/GRU
- Deep RNN/LSTM/GRU architectures
- Sequential data processing

### 📊 Model Development

- Data preprocessing
- Training & validation
- Model evaluation
- Hyperparameter experimentation
- Overfitting & regularization
- Performance analysis
